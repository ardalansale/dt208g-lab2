En enkel todo‑applikation byggd i TypeScript där uppgifter sparas i LocalStorage.  
Projektet demonstrerar DOM‑hantering, validering och lagring i webbläsaren.

##Publicerad webbplats
https://todo-typescript-ardalan.netlify.app

## GitHub‑repo
https://github.com/ardalansale/dt208g-lab2

## Funktionalitet
- Visa alla todos  
- Lägg till nya todos  
- Markera todo som klar / inte klar  
- Ta bort todo med bekräftelseruta  
- Prioritet visas som **Hög / Medel / Låg**  
- Datum för när uppgiften skapades  
- Lagring i LocalStorage  
- Minimalistisk design  

## Tekniker
- TypeScript

- HTML

- LocalStorage
